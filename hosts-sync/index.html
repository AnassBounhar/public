Hosts Sync

Keep your system hosts file synchronized from a Git repository. Runs in the tray on Windows, in the menu bar on macOS, and in the top bar on Ubuntu.

Windows

  • Portable zip .zip

Extract the zip and run HostsSyncApp.exe as Administrator.

Linux

  • Portable zip .zip

Extract the zip and run ./HostsSync/HostsSync. For desktop integration and the privileged helper, clone the Git repo and run ./run-linux.sh install.

macOS

  • Apple silicon app .zip
  • Intel app .zip

Extract the zip and open Hosts Sync.app. The app stays in the menu bar.

These builds are unsigned, so Windows and macOS may warn on the first launch. The same files are listed on the GitHub release. Source code lives at AnassBounhar/hosts.
